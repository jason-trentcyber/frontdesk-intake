# ADR-0003: Auth.js with Google and GitHub OAuth, identities in our Postgres

Status: decided 2026-09-07. The "via the Prisma adapter" clause is superseded by ADR-0018 (`@auth/drizzle-adapter`); everything else stands.

## Decision
- Next.js app uses Auth.js with Google and GitHub providers. Sessions and users live in our Postgres via the Prisma adapter.
- A user is mapped to an org through an `org_members` allow-list (email → org, role). Signing in without a mapping shows a "not a member of any org" page.
- Owners edit the allow-list from the UI; seeds create the initial entries.
- API keys (F3) are per-org, hashed at rest, shown once.

## Rejected
- Supabase Auth: adds a hosted dependency outside Terraform and breaks "values-file swap to EKS".
- Invite-only or self-serve signup: not needed with two seeded orgs; revisit with self-serve orgs.
